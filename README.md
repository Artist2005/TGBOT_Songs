# 🎵 Telegram Music Explorer Bot (`TGBOT_Songs`)

Швидкий двомовний (**🇺🇦 Українська / 🇬🇧 English**) Telegram-бот для пошуку за назвою, виконавцем або **словами з пісні**, прослуховування 30-секундних прев'ю та завантаження повних MP3 треків (192 kbps) у будь-якому чаті.

## ✨ Можливості
- **Пошук за назвою, виконавцем або словами з пісні:**
  - Введіть назву треку, виконавця або просто **рядок із тексту пісні, який пам'ятаєте** (українською чи англійською) — як у чаті з ботом, так і через `@bot_name` у будь-якому чаті.
- **Інлайн-режим (`@bot_name`):**
  - Показує 30-секундне прев'ю з симетричною панеллю `2×2` та кнопкою **«📥 Скачати MP3»**, яка замінює прев'ю на повний трек прямо в тому ж повідомленні.
  - Порожній запит (`@bot_name `) миттєво відкриває **🔥 Топ-10 світових хітів Deezer**.
  - Запит `@bot_name fav` (або `@bot_name ❤️`) відкриває ваш особистий плейлист **Вибраного**.
- **Завантаження за посиланням:**
  - Надішліть боту посилання з **YouTube, YouTube Shorts, SoundCloud, TikTok, Instagram Reels** або **Spotify** — бот автоматично витягне чистий MP3 з обкладинкою.
- **Симетрична панель `2×2` під кожним треком (у чаті та інлайні):**
  - `🤍 Вибране / ❤️ Вибране` — зберегти трек у власний плейлист (`/favorites`).
  - `📜 Текст` — повний текст пісні (LRCLIB + NetEase + lyrics.ovh) зі зручною посторінковою навігацією `⬅️ / 📄 / ➡️`.
  - `🎛 Ефекти` — генерація `🌙 Slowed + Reverb`, `⚡ Speed Up` та `🔊 Bass Boost` версій у 1 клік через FFmpeg (із заміною на місці в інлайн-режимі).
  - `📻 Схожі` — підбір схожих треків та хітів виконавця.
- **Команди:**
  - `/start` — головне меню
  - `/top` — Топ-10 світових хітів
  - `/favorites` (`/fav`) — збережені улюблені треки
  - `/lang` — перемикання мови інтерфейсу (🇺🇦 / 🇬🇧)
  - `/admin` (`/stats`) — закрита адмін-панель статистики та очищення кешу (лише для власника бота)
