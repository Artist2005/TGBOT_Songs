# 🎵 Telegram Music Explorer Bot (`TGBOT_Songs`)

Швидкий двомовний (**🇺🇦 Українська / 🇬🇧 English**) Telegram-бот для пошуку, прослуховування 30-секундних прев'ю та завантаження повних MP3 треків (192 kbps) у будь-якому чаті.

## ✨ Можливості
- **Інлайн-режим (`@bot_name`):**
  - Введіть `@bot_name назва пісні` у будь-якому чаті — бот покаже 30-секундне прев'ю з кнопкою **«📥 Завантажити MP3»**, яка замінює прев'ю на повний трек прямо в тому ж повідомленні.
  - Порожній запит (`@bot_name `) миттєво відкриває **🔥 Топ-10 світових хітів Deezer**.
  - Запит `@bot_name fav` (або `@bot_name ❤️`) відкриває ваш особистий плейлист **Вибраного**.
- **Завантаження за посиланням:**
  - Надішліть боту посилання з **YouTube, YouTube Shorts, SoundCloud, TikTok, Instagram Reels** або **Spotify** — бот автоматично витягне чистий MP3 з обкладинкою.
- **Ненав'язлива панель під кожним MP3:**
  - `🤍 / ❤️` — зберегти трек у власний плейлист (`/favorites`).
  - `📜 Текст` — повний текст пісні (Lyrics через LRCLIB) у згортаному блоці `<blockquote expandable>`.
  - `🎛 Ефекти` — генерація `🌙 Slowed + Reverb`, `⚡ Speed Up` та `🔊 Bass Boost` версій у 1 клік через FFmpeg.
  - `📻 Схожі` — підбір схожих треків та хітів виконавця.
- **Команди:**
  - `/start` — головне меню
  - `/top` — Топ-10 світових хітів
  - `/favorites` (`/fav`) — збережені улюблені треки
  - `/lang` — перемикання мови інтерфейсу (🇺🇦 / 🇬🇧)
